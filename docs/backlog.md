# Neste leveranser

1. Bekreft dagens prosess og de åpne spørsmålene i prosjektbeskrivelsen med salgsteamet; test registrering og oppfølging med fiktive eksempler.
2. Velg godkjent driftsmiljø, identitetsløsning og datalagring. Avklar tilgangsmatrise, tenant, formål og behandling av sensitive opplysninger.
3. Bygg server/API, normaliserte kontakter/relasjoner/saker, servervalidering og tilgang på avdeling/team/tildeling. Test at uvedkommende ikke kan lese, søke, endre eller eksportere.
4. Bygg reell overlevering, revisjonssikker historikk, kontaktønsker, oppgaver og påminnelser. Definer eierskifte separat fra mottaksbekreftet overlevering.
5. Kontrollert nettskjemainntak og prøveimport fra dagens løsning, med feltmapping, idempotens, avstemming og feilkø. Ingen full innbokskopiering.
6. Rapportdefinisjoner, mål, datakvalitet og historikk. Test sikkerhetskopi/gjenoppretting, sletting, eksport og tilgang før produksjon.

Senere: valgt e-post og kalender, dokumentkobling, AI-utkast etter eget mandat. Ingen automatisk utsendelse, samtaleopptak eller AI-rangering i beta.
